# Clínica Vida e Beleza — Estética Avançada

Landing page demonstrativa para a Clínica Vida e Beleza, em Pituba, Salvador.

## Rotas

- `/` — apresentação completa
- `/links` — página de links
- `/privacidade` — política-base de privacidade, cookies e LGPD
- `/proposta` — protótipo de proposta comercial com downloads em PDF e DOCX

## Desenvolvimento

```bash
npm install
npm run dev
```

## Validação

```bash
npm run build
npm run test:e2e
```

O projeto é uma demonstração comercial não oficial. Conteúdo, identidade, política de privacidade, imagens e informações clínicas devem ser aprovados pela clínica antes de qualquer publicação definitiva.
